# Демо 3 — калькулятор «Цена ошибки AI-агента»

Офлайн-калькулятор матрицы «автомат / копилот / человек». Один самодостаточный HTML-файл: всё инлайн, внешних зависимостей нет, работает с `file://` без интернета.

## Как открыть

```
open index.html
```

## Как пользоваться

1. Вбейте свой процесс в поле 1 (автокредит, антифрод, KYC, кэшбэк).
2. Задайте объём и ущерб ошибки — всё пересчитывается мгновенно, кнопки «посчитать» нет.
3. Смотрите вердикт и классификацию по матрице. Правило классификации написано на экране.
4. Двигайте «долю проверки человеком» от 100% к 0% и смотрите, где экономия ломается: это граница между копилотом и автоматом для этого процесса.

Главный тезис: решает арифметика ущерба. Процент ошибок сам по себе ничего не значит. Агент с 10% ошибок может окупаться. Агент с 1% ошибок может быть убыточен, если одна ошибка стоит миллионы.

## Сценарий 1. Автокредит (дефолт при открытии)

| Поле | Значение |
|---|---|
| Процесс | Проверка кредитных заявок |
| Объём | 1 000 задач/день |
| Частота ошибок | 10% |
| Ущерб ошибки | 15 000 ₽ |
| Обнаружимость | 80% |
| Проверка задачи | 300 ₽ |
| Доля проверки | 100% |
| Ручное выполнение | 800 ₽ |

Расчёт: цена ошибок 300 000 ₽/день, проверка 300 000 ₽/день, ручной процесс 800 000 ₽/день. Экономия **+200 000 ₽/день, +4 400 000 ₽/мес**. Вердикт: **ОКУПАЕТСЯ, КОПИЛОТ**. Без проверки (доля 0%) ошибки стоят 1 500 000 ₽/день — автомат убыточен, поэтому режим копилот.

Вывод: даже «сырой» агент с 10% ошибок выгоден, когда ущерб ошибки умеренный и проверка дешевле выполнения.

## Сценарий 2. Антифрод

| Поле | Значение |
|---|---|
| Процесс | Проверка подозрительных транзакций |
| Объём | 1 000 задач/день |
| Частота ошибок | 1% |
| Ущерб ошибки | 2 000 000 ₽ |
| Обнаружимость | 80% |
| Проверка задачи | 300 ₽ |
| Доля проверки | 100% |
| Ручное выполнение | 800 ₽ |

Расчёт: цена ошибок 4 000 000 ₽/день (10 ошибок в день, 2 незамеченные по 2 млн), проверка 300 000 ₽/день. Экономия **−3 500 000 ₽/день**. Вердикт: **НЕ ОКУПАЕТСЯ, ЧЕЛОВЕК**.

Вывод: при катастрофическом ущербе даже 1% ошибок недопустим. Агент возможен максимум как ассистент, который готовит материалы, а решение принимает человек. Поле 8 (ручное выполнение) здесь почти перестаёт влиять: ущерб на порядки больше стоимости труда.

## Сценарий 3. KYC-скрининг

| Поле | Значение |
|---|---|
| Процесс | Первичный скрининг документов KYC |
| Объём | 5 000 задач/день |
| Частота ошибок | 2% |
| Ущерб ошибки | 2 000 ₽ |
| Обнаружимость | 90% |
| Проверка задачи | 300 ₽ |
| Доля проверки | 20% |
| Ручное выполнение | 800 ₽ |

Расчёт: цена ошибок 164 000 ₽/день (выборочная проверка 20% задач при обнаружимости 90% предотвращает 18 из 100 ошибок), проверка 300 000 ₽/день (1000 проверенных × 300 ₽), ручной процесс 4 000 000 ₽/день. Экономия **+3 536 000 ₽/день**. Вердикт: **ОКУПАЕТСЯ, АВТОМАТ** — даже при нулевой проверке ошибки стоят 200 000 ₽/день против 4 млн ручного труда.

Вывод: рутина с малым ущербом — кандидат на полный автомат. Проверку можно оставить выборочной (20%) для контроля дрейфа качества, и экономика всё равно сходится.

## Про ставки по умолчанию

Ручное выполнение задачи (800 ₽) по умолчанию дороже проверки готового результата агента (300 ₽): проверить готовый ответ быстрее, чем произвести его с нуля. Ставки — параметры, подставляйте свои.
