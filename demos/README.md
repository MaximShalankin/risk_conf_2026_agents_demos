# Демо семинара «Цена ошибки AI-агента» (Risk Conference, 15.10.2026)

Пять живых демо (демо 3 — офлайн-страница). Всё локально: ollama, temperature 0, интернет не нужен. Основная модель контура — `qwen3:4b-instruct-2507-q4_K_M`; демо 5 дополнительно использует `llama3.2:1b`, `qwen3.5:9b`, `gemma4:12b`.

## Порядок демо (дуга семинара)

| Цикл | Демо | Папка | Запуск |
|---|---|---|---|
| 1. Ошибка агента не похожа на ошибку софта | «Уверенный ответ» | `demo1_confident/` | `./run.sh` |
| 2. Частоту можно измерить до внедрения | «Харнесс в прямом эфире» | `demo2_harness/` | `./run.sh` |
| 3. Решает экономика | Калькулятор матрицы | `demo3_calculator/` | `open index.html` |
| 4. Ошибку можно сделать дешёвой | «Тот же отказ, но с верификатором» | `demo4_verifier/` | `./run.sh` |
| 4. …сразу после демо 4 | «Пять агентов» (голосование) | `demo5_consensus/` | `./run.sh` |

Дуга семинара: демо 1, 4 и 5 — один и тот же вход (договор + вопрос). В цикле 1 ошибка проходит незамеченной, в цикле 4 та же ошибка ловится вторым контуром, а голосование флота агентов её не ловит — все четыре модели ошибаются одинаково.

## Подготовка к прогону

1. `ollama serve` запущен, модели скачаны: `ollama pull qwen3:4b-instruct-2507-q4_K_M` и для демо 5 — `llama3.2:1b`, `qwen3.5:9b`, `gemma4:12b`
2. Прогреть модели: `./demo1_confident/run.sh` до первого ответа, Ctrl+C; для демо 5 — `ollama run <модель> ""` для каждой из четырёх
3. Демо 3: открыть `demo3_calculator/index.html` в браузере
